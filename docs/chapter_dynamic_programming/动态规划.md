🧭 动态规划学习的五步捷径法

✅ 1. 只学“套路”，不学“题型”

很多初学者会迷失在各种题型（背包、LIS、打家劫舍、矩阵DP等），但这些只是表象。

真正的本质是：

动态规划 = 明确状态 + 确定转移方程 + 记住之前的结果

⸻

✅ 2. 掌握 “五部曲” 模板

经典 DP 模板是：
	1.	状态定义：dp[i] / dp[i][j] 是什么含义？代表什么子问题？
	2.	转移方程：从哪些状态转移到当前状态？
	3.	初始化：边界情况如何设置？
	4.	遍历顺序：从前往后 or 递归记忆化？
	5.	返回值：最终要求解的状态是哪个？

练习任何题时，都写这五句话，就像套模板一样。

⸻

✅ 3. 从三道题打通任督二脉

以下三题练透，几乎能打开大门：

问题	学到什么
爬楼梯（斐波那契型）	线性递推、记忆优化
打家劫舍	状态依赖跳跃、分支对比
最长递增子序列 LIS	状态与位置关系、非连续选择

这三题分别代表：线性 DP、跳跃式 DP、非连续选择型 DP，把这些套路吃透，其他题都是变形。

⸻

✅ 4. 统一视角：问题 = 原问题 + 子问题

所有 DP 本质上都是：

用已知子问题的解，构造出更大的问题的解

只要你问自己：“我能不能从规模更小的解推出当前解？”那你就在用 DP 思维。

⸻

✅ 5. 反复写、反复总结，不怕一题多解

动态规划的精华在于“递归转移的思想”，不是代码技巧

多尝试：
	•	自顶向下（带记忆的递归）
	•	自底向上（DP数组迭代）
	•	滚动数组优化
	•	空间压缩（二维变一维）

⸻

🚀 实用建议（来自刷题经验）
	•	动手写公式大于看答案
	•	不怕卡壳，哪怕 30 分钟写不出，也不要看题解，先把五部曲列出来
	•	写完之后总结一句话：“这个问题的 dp[i] 是怎么来的？”
