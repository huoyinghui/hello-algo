## 🔥 重点掌握

### Python技巧🐍
```python
# 1. 列表推导式
result = [x for x in nums if x > 0]

# 2. defaultdict自动初始化
from collections import defaultdict
graph = defaultdict(list)

# 3. Counter快速计数
from collections import Counter
counter = Counter(nums)

# 4. deque实现队列
from collections import deque
queue = deque()
queue.append(x)     # 入队
queue.popleft()     # 出队 O(1)

# 5. set集合运算
s1 & s2  # 交集
s1 | s2  # 并集
```

### 核心模板
```python
# 快慢指针模板
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next

# 虚拟头节点模板
dummy = ListNode(0)
dummy.next = head

# 栈模板
stack = []
stack.append(x)  # 入栈
stack.pop()      # 出栈
stack[-1]        # 栈顶

# 哈希表模板
seen = {}
if key in seen:
    # ...
seen[key] = value
```

## 🎯 学习建议

1. **每天固定时间刷题**: 建议晚上7-10点,保证3小时学习
2. **先理解再刷题**: 不要急于刷题,先看文档理解原理
3. **及时总结**: 每道题做完写注释,总结技巧
4. **重复练习**: 第一遍不会很正常,标记后过几天再做
5. **使用Python特性**: 充分利用Python的语法糖和内置库
