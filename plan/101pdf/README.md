- [ ] Python常用数据结构（list、dict、set）
- [ ] Python标准库（collections、heapq、bisect）
- [ ] 数组与链表基础
- [ ] 栈与队列操作
- [ ] 哈希表应用

**推荐阅读顺序**：
1. `mindmaps/01-基础数据结构脑图.md` - 建立整体认知

## 📖 学习方法建议

### 1️⃣ 先看脑图，建立框架
- 每个主题先看对应的思维导图
- 理解知识点之间的关系
- 在脑海中构建知识体系

### 2️⃣ 深入学习知识点
- 阅读`knowledge/`目录下的详细讲解
- 理解核心概念和关键技巧
- 对比Python和其他语言的区别

### 3️⃣ 动手实现数据结构
- 跟着`data-structures/`目录练习
- 自己实现一遍核心数据结构
- 理解底层原理

### 4️⃣ 掌握算法模板
- 背诵`templates/`目录下的模板
- 理解每一行代码的作用
- 能默写出核心框架

### 5️⃣ 大量刷题练习
- 按照`practice/`目录的计划刷题
- 先做简单题建立信心
- 遇到难题先看思路再实现

### 6️⃣ 定期复习总结
- 每周回顾本周学习内容
- 整理易错点和技巧
- 更新自己的笔记
