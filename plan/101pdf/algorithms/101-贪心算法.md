# 1.贪心算法

## 1.1 算法解释

**贪心算法**（Greedy Algorithm）是一种在每一步选择中都采取当前状态下最优选择的算法策略，期望通过局部最优选择达到全局最优解。

**核心思想：**
- 将问题分解为若干子问题
- 对每个子问题求解，得到子问题的局部最优解
- 将子问题的局部最优解合成原问题的解

**适用条件：**
1. **贪心选择性质**：局部最优选择能导致全局最优解
2. **最优子结构**：问题的最优解包含其子问题的最优解

**与动态规划的区别：**
- 贪心算法：每一步做出当前最优选择，不回溯
- 动态规划：保存子问题的解，可能需要回溯比较

## 1.2 基本框架

```python
def greedy_algorithm(problem):
    # 1. 初始化
    result = []
    
    # 2. 按照贪心策略排序或处理数据
    data = sort_or_process(problem)
    
    # 3. 每次选择局部最优
    for item in data:
        if is_valid(item, result):
            result.append(item)
    
    # 4. 返回结果
    return result
```

## 1.3 经典问题类型

### 1.3.1 区间调度问题
- 活动选择问题
- 会议室安排
- 无重叠区间

**策略**：按结束时间排序，选择最早结束的活动

### 1.3.2 分配问题
- 分发饼干
- 分发糖果（LeetCode 135）
- 任务分配

**策略**：排序后进行匹配或多次遍历

### 1.3.3 区间覆盖问题
- 跳跃游戏
- 最少箭引爆气球
- 视频拼接

**策略**：贪心选择能覆盖最远距离的点

### 1.3.4 字符串构造问题
- 移掉 K 位数字
- 去除重复字母
- 摆动序列

**策略**：单调栈或贪心选择

## 1.4 解题步骤

1. **分析问题**：判断是否满足贪心选择性质
2. **确定贪心策略**：找到局部最优的选择标准
3. **证明正确性**：证明局部最优能导致全局最优
4. **编码实现**：通常需要排序 + 遍历
5. **验证测试**：用边界案例验证

## 1.5 常见贪心策略

- **按开始时间排序**：区间调度类问题
- **按结束时间排序**：活动选择类问题
- **按长度排序**：分配类问题
- **按比值排序**：背包类问题
- **维护单调性**：字符串构造问题
- **两次遍历**：双向约束问题（如分发糖果）

## 1.6 注意事项

⚠️ **贪心算法不总是能得到最优解**
- 需要严格证明贪心选择性质
- 反例：0-1背包问题（需要用动态规划）
- 如果贪心策略不确定，考虑动态规划

✅ **贪心算法的优势**
- 时间复杂度通常为 O(n log n)（排序）或 O(n)
- 空间复杂度低，通常为 O(1)
- 代码简洁，易于实现
