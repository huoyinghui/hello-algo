## 🎯 使用建议

### 学习顺序
1. **新手入门** → 从数据结构和搜索算法开始
2. **进阶提升** → 掌握动态规划和图论算法
3. **效率优化** → 熟练运用Python技巧

### 背诵重点
标记 🔥 的内容是刷题高频模板，建议优先背诵：
- 并查集
- 快速排序
- 二分查找（所有变体）
- BFS/DFS
- 0-1背包
- 最长递增子序列
- 拓扑排序
- Dijkstra算法
- Python常用模块（collections, heapq, bisect）

### 实践建议
- 每个模板至少手写3遍
- 结合LeetCode题目实践
- 理解模板的时间/空间复杂度
- 记住模板的适用场景

## 📊 复杂度速查表

| 算法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 快速排序 | O(n log n) | O(log n) |
| 归并排序 | O(n log n) | O(n) |
| 二分查找 | O(log n) | O(1) |
| DFS/BFS | O(V + E) | O(V) |
| 0-1背包 | O(n × W) | O(W) |
| LIS（二分） | O(n log n) | O(n) |
| Dijkstra | O((V+E) log V) | O(V) |
| Floyd | O(V³) | O(V²) |
| 拓扑排序 | O(V + E) | O(V) |
