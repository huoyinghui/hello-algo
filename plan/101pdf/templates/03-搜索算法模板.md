## 1. 二分查找 🔥

### 1.1 基础二分

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

**使用场景：** 有序数组查找  
**时间复杂度：** O(log n)

---

### 1.2 左边界（lower_bound）

```python
def lower_bound(nums, target):
    """找到第一个 >= target 的位置"""
    left, right = 0, len(nums)
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left
```

**返回值：**
- 第一个 >= target 的索引
- 如果都小于target，返回 len(nums)

---

### 1.3 右边界（upper_bound）

```python
def upper_bound(nums, target):
    """找到最后一个 <= target 的位置"""
    left, right = 0, len(nums)
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] <= target:
            left = mid + 1
        else:
            right = mid
    return left - 1
```

**返回值：**
- 最后一个 <= target 的索引
- 如果都大于target，返回 -1

### 1.4 二分答案模板

```python
def binary_search_answer(check_func, left, right):
    """寻找满足条件的最小/最大值"""
    while left < right:
        mid = left + (right - left) // 2
        if check_func(mid):
            right = mid  # 寻找最小值
            # left = mid + 1  # 寻找最大值
        else:
            left = mid + 1  # 寻找最小值
            # right = mid  # 寻找最大值
    return left
```

## 2. DFS 深度优先搜索

### 2.1 递归版DFS

```python
def dfs(graph, node, visited):
    """图的DFS遍历"""
    visited.add(node)
    # 处理当前节点
    
    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)

# 使用示例
graph = {0: [1, 2], 1: [0, 3], 2: [0], 3: [1]}
visited = set()
dfs(graph, 0, visited)
```

---

### 2.2 迭代版DFS

```python
def dfs_iterative(graph, start):
    """使用栈实现DFS"""
    visited = set()
    stack = [start]
    
    while stack:
        node = stack.pop()
        if node in visited:
            continue
        visited.add(node)
        # 处理节点
        
        for neighbor in graph[node]:
            if neighbor not in visited:
                stack.append(neighbor)
    
    return visited
```

### 2.3 回溯模板

```python
def backtrack(path, choices):
    """回溯算法通用模板"""
    if 满足结束条件:
        result.append(path[:])
        return
    
    for choice in choices:
        # 做选择
        path.append(choice)
        
        # 递归

        # 撤销选择

# 具体例子：全排列
def permute(nums):
    result = []
    
    def backtrack(path, remaining):
        if not remaining:
            result.append(path[:])
            return
        
        for i in range(len(remaining)):
            backtrack(path + [remaining[i]], 
                     remaining[:i] + remaining[i+1:])
    
    backtrack([], nums)
    return result
```

## 3. BFS 广度优先搜索 🔥

### 3.1 基础BFS

```python
from collections import deque

def bfs(graph, start):
    """图的BFS遍历"""
    visited = {start}
    queue = deque([start])
    
    while queue:
        node = queue.popleft()
        # 处理当前节点
        
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    
    return visited
```

---

### 3.2 分层BFS

```python
def bfs_level(graph, start):
    """按层遍历，常用于最短路径"""
    visited = {start}
    queue = deque([start])
    level = 0
    
    while queue:
        size = len(queue)
        for _ in range(size):
            node = queue.popleft()
            # 处理当前层节点
            
            for neighbor in graph[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        level += 1
    
    return level
```

---

### 3.3 双向BFS（优化）

```python
def bidirectional_bfs(graph, start, end):
    """双向BFS，效率更高"""
    if start == end:
        return 0
    
    front = {start}
    back = {end}
    visited = {start, end}
    steps = 0
    
    while front and back:
        # 优化：从较小的集合开始扩展
        if len(front) > len(back):
            front, back = back, front
        
        next_level = set()
        for node in front:
            for neighbor in graph[node]:
                if neighbor in back:
                    return steps + 1
                if neighbor not in visited:
                    visited.add(neighbor)
                    next_level.add(neighbor)
        
        front = next_level
        steps += 1
    
    return -1
```

**典型例题：**
- LeetCode 127. 单词接龙
- LeetCode 752. 打开转盘锁

## 4. 网格DFS/BFS

### 4.1 网格DFS

```python
def grid_dfs(grid, i, j, visited):
    """二维网格DFS"""
    rows, cols = len(grid), len(grid[0])
    
    if i < 0 or i >= rows or j < 0 or j >= cols:
        return
    if (i, j) in visited or grid[i][j] == 0:
        return
    
    visited.add((i, j))
    
    # 四个方向
    directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
    for di, dj in directions:
        grid_dfs(grid, i + di, j + dj, visited)
```

---

### 4.2 网格BFS

```python
from collections import deque

def grid_bfs(grid, start_i, start_j):
    """二维网格BFS"""
    rows, cols = len(grid), len(grid[0])
    visited = {(start_i, start_j)}
    queue = deque([(start_i, start_j, 0)])  # (i, j, distance)
    
    directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
    
    while queue:
        i, j, dist = queue.popleft()
        
        for di, dj in directions:
            ni, nj = i + di, j + dj
            if 0 <= ni < rows and 0 <= nj < cols:
                if (ni, nj) not in visited and grid[ni][nj] != 0:
                    visited.add((ni, nj))
                    queue.append((ni, nj, dist + 1))
```

**典型例题：**
- LeetCode 200. 岛屿数量（DFS）
- LeetCode 994. 腐烂的橘子（BFS）
- LeetCode 542. 01矩阵（BFS）

## 搜索算法选择指南

| 场景 | 推荐算法 | 理由 |
|------|---------|------|
| 有序数组查找 | 二分查找 | O(log n)效率最高 |
| 最短路径 | BFS | 逐层扩展保证最短 |
| 连通性、路径存在性 | DFS | 实现简单 |
| 全排列、组合 | 回溯DFS | 需要穷举所有可能 |
| 最小步数 | BFS分层 | 记录层数即步数 |
