## 1. 记忆化搜索 🐍

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def dp(n):
    """斐波那契数列"""
    if n <= 1:
        return n
    return dp(n-1) + dp(n-2)

# 或使用字典
def dp_with_memo(n, memo={}):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = dp_with_memo(n-1, memo) + dp_with_memo(n-2, memo)
    return memo[n]
```

**优点：** 代码简洁，自顶向下  
**使用场景：** 递归关系清晰的问题

## 2. 0-1背包 🔥

### 2.1 二维DP

```python
def knapsack_01(weights, values, capacity):
    """
    weights: 物品重量列表
    values: 物品价值列表
    capacity: 背包容量
    """
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            # 不选第i个物品
            dp[i][w] = dp[i-1][w]
            # 选第i个物品（如果放得下）
            if w >= weights[i-1]:
                dp[i][w] = max(dp[i][w], 
                              dp[i-1][w-weights[i-1]] + values[i-1])
    
    return dp[n][capacity]
```

**时间复杂度：** O(n × capacity)  
**空间复杂度：** O(n × capacity)

---

### 2.2 一维DP（空间优化）🐍

```python
def knapsack_01_optimized(weights, values, capacity):
    """空间优化版本"""
    dp = [0] * (capacity + 1)
    
    for i in range(len(weights)):
        # 必须倒序遍历！
        for w in range(capacity, weights[i] - 1, -1):
            dp[w] = max(dp[w], dp[w-weights[i]] + values[i])
    
    return dp[capacity]
```

**时间复杂度：** O(n × capacity)  
**空间复杂度：** O(capacity)

**⚠️ 注意：** 必须倒序遍历，避免重复使用物品

## 3. 完全背包

```python
def knapsack_complete(weights, values, capacity):
    """物品可以无限使用"""
    dp = [0] * (capacity + 1)
    
    for i in range(len(weights)):
        # 正序遍历！
        for w in range(weights[i], capacity + 1):
            dp[w] = max(dp[w], dp[w-weights[i]] + values[i])
    
    return dp[capacity]
```

**与0-1背包的区别：**
- 0-1背包：倒序遍历 `range(capacity, w-1, -1)`
- 完全背包：正序遍历 `range(w, capacity+1)`

**典型例题：**
- LeetCode 322. 零钱兑换
- LeetCode 518. 零钱兑换 II

## 4. 最长递增子序列 (LIS) 🔥

### 4.1 DP解法 O(n²)

```python
def length_of_lis_dp(nums):
    """动态规划解法"""
    if not nums:
        return 0
    
    n = len(nums)
    dp = [1] * n
    
    for i in range(1, n):
        for j in range(i):
            if nums[i] > nums[j]:
                dp[i] = max(dp[i], dp[j] + 1)
    
    return max(dp)
```

---

### 4.2 二分优化 O(n log n) 🐍

```python
import bisect

def length_of_lis(nums):
    """
    tails[i]: 长度为i+1的递增子序列的最小末尾元素
    """
    tails = []
    
    for num in nums:
        pos = bisect.bisect_left(tails, num)
        if pos == len(tails):
            tails.append(num)
        else:
            tails[pos] = num
    
    return len(tails)
```

**时间复杂度：** O(n log n)  
**典型例题：** LeetCode 300. 最长递增子序列

## 5. 最长公共子序列 (LCS)

```python
def longest_common_subsequence(text1, text2):
    """
    dp[i][j]: text1[:i] 和 text2[:j] 的LCS长度
    """
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    
    return dp[m][n]
```

**典型例题：** LeetCode 1143. 最长公共子序列

## 6. 编辑距离

```python
def min_distance(word1, word2):
    """
    最少操作次数将word1转换为word2
    操作：插入、删除、替换
    """
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    # 初始化
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = min(
                    dp[i-1][j] + 1,    # 删除
                    dp[i][j-1] + 1,    # 插入
                    dp[i-1][j-1] + 1   # 替换
                )
    
    return dp[m][n]
```

**典型例题：** LeetCode 72. 编辑距离

## 7. 股票买卖问题

### 7.1 最多一次交易

```python
def max_profit(prices):
    """只能买卖一次"""
    min_price = float('inf')
    max_profit = 0
    
    for price in prices:
        min_price = min(min_price, price)
        max_profit = max(max_profit, price - min_price)
    
    return max_profit
```

---

### 7.2 无限次交易

```python
def max_profit_unlimited(prices):
    """可以多次买卖"""
    profit = 0
    for i in range(1, len(prices)):
        if prices[i] > prices[i-1]:
            profit += prices[i] - prices[i-1]
    return profit
```

---

### 7.3 最多k次交易

```python
def max_profit_k(k, prices):
    """最多k次交易"""
    if not prices:
        return 0
    
    n = len(prices)
    if k >= n // 2:
        # 等同于无限次交易
        return max_profit_unlimited(prices)
    
    # dp[i][j][0]: 第i天，最多j次交易，当前不持有
    # dp[i][j][1]: 第i天，最多j次交易，当前持有
    dp = [[[0, 0] for _ in range(k + 1)] for _ in range(n)]
    
    for i in range(n):
        for j in range(1, k + 1):
            if i == 0:
                dp[0][j][0] = 0
                dp[0][j][1] = -prices[0]
                continue
            
            dp[i][j][0] = max(dp[i-1][j][0], dp[i-1][j][1] + prices[i])
            dp[i][j][1] = max(dp[i-1][j][1], dp[i-1][j-1][0] - prices[i])
    
    return dp[n-1][k][0]
```

**典型例题：**
- LeetCode 121. 买卖股票的最佳时机
- LeetCode 122. 买卖股票的最佳时机 II
- LeetCode 188. 买卖股票的最佳时机 IV

## 8. 打家劫舍系列

### 8.1 基础版

```python
def rob(nums):
    """不能抢相邻的房子"""
    if not nums:
        return 0
    if len(nums) == 1:
        return nums[0]
    
    prev2, prev1 = 0, 0
    for num in nums:
        curr = max(prev1, prev2 + num)
        prev2, prev1 = prev1, curr
    
    return prev1
```

---

### 8.2 环形排列

```python
def rob_circular(nums):
    """房子围成一圈"""
    if len(nums) == 1:
        return nums[0]
    
    def rob_range(start, end):
        prev2, prev1 = 0, 0
        for i in range(start, end):
            curr = max(prev1, prev2 + nums[i])
            prev2, prev1 = prev1, curr
        return prev1
    
    # 不抢第一个 或 不抢最后一个
    return max(rob_range(0, len(nums)-1), rob_range(1, len(nums)))
```

**典型例题：**
- LeetCode 198. 打家劫舍
- LeetCode 213. 打家劫舍 II

## DP问题分类

| 类型 | 典型问题 | 状态定义 |
|------|---------|---------|
| 线性DP | 最长递增子序列 | dp[i]: 以i结尾的... |
| 背包DP | 0-1背包、完全背包 | dp[i][w]: 前i个物品... |
| 区间DP | 最长回文子串 | dp[i][j]: 区间[i,j]... |
| 树形DP | 打家劫舍III | dp[node][0/1] |
| 状态机DP | 股票买卖 | dp[i][k][0/1] |
| 数位DP | 数字范围统计 | dp[pos][状态] |
